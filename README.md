# Личный сайт-портфолио (Хурсанд Атажанов)

Чистые HTML, CSS и JS без сборки. Работает на GitHub Pages как есть.

```
index.html      главная
hr.html         страница для рекрутеров и ИИ (статический текст + JSON-LD)
404.html        страница «не найдено»
css/style.css   все стили
js/main.js      подставляет тексты из content/ в страницу
js/edit.js      режим редактирования (грузится только при #edit)
content/*.json  все тексты главной
images/         favicon.svg, сюда же avatar.jpg и full.jpg
design/         эталонный макет template2.html (в навигации не участвует)
```

## Локальный запуск

Тексты подгружаются через `fetch`, а он не работает при открытии файла двойным кликом
(`file://`). Запускайте через локальный сервер:

```bash
python3 -m http.server 8000
```

(на Windows: `python -m http.server 8000`) и откройте http://localhost:8000/.
Если JSON не загрузился, на странице остаются заглушки «Текст не загрузился…».

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте код (ветка `main`).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://USER.github.io/REPO/`. Все пути в проекте относительные.
4. После публикации добавьте в `<head>` страниц абсолютный `og:image`
   (пример лежит комментарием в `index.html`) и поле `url` в JSON-LD в `hr.html`.

## Как менять контент

Правка файла в `content/` = правка сайта, вёрстку трогать не нужно.

| Файл | Что внутри |
| --- | --- |
| `profile.json` | имя, строки в баннере, кнопка |
| `now.json` | блок «Сейчас» |
| `about.json` | «Кто я» |
| `works.json` | «Путь и работы»: `date`, `title`, `text`, `url` |
| `skills.json` | «Навыки и видение» |
| `hours.json` | «Время работы» |
| `links.json` | «Ссылки», кнопки-ссылки и «Контакты» в подвале |

Везде, где стоит `добавить`, нужно вписать свой текст. Новые записи в `works.json` добавляйте
в начало списка `entries`: они показываются сверху. Пустой `url` значит, что ссылки нет.
Заголовки записей автоматически попадают в подменю «Работы».

`hr.html` специально статический (роботы и ИИ часто не выполняют JS), его тексты правятся прямо в файле.

## Режим редактирования

1. Откройте сайт (локально или на Pages) с `#edit` в адресе: `http://localhost:8000/index.html#edit`
   (если страница уже открыта, добавьте `#edit` и обновите её).
2. Все тексты станут полями, которые растут по мере ввода. Для записей в «Пути и работах»
   есть кнопки добавления и удаления, под ссылками и кнопками появляются поля адреса.
3. Внизу нажмите **Скачать JSON**: скачаются только изменённые файлы (`now.json` и т. д.).
   Браузер может спросить разрешение на несколько загрузок.
4. Положите скачанные файлы в `content/` с заменой, сделайте коммит и запушьте.

**Важно:** правка в браузере сама на сайте не публикуется и никуда не сохраняется. Пока вы
не скачали JSON и не закоммитили его, изменения живут только в открытой вкладке.
Обычные посетители режим не видят, он включается только адресом с `#edit`.

## Фото

Если файла нет, показывается силуэт из макета. Положите:

- `images/avatar.jpg` — круглое фото профиля, квадрат 760×760 px (показывается 380 px);
- `images/full.jpg` — фото во весь рост, пропорция 3:5, например 600×1000 px.

Сожмите JPG до 80–150 КБ (например в Squoosh). Размеры в разметке заданы, страница при загрузке не прыгает.
Файл должен называться именно так (`.jpg`).

## Тема и доступность

Светлая и тёмная темы переключаются автоматически по `prefers-color-scheme`. Есть ссылка
«К содержимому», видимый фокус, подменю открывается по Tab и закрывается по Esc,
плавная прокрутка отключается при `prefers-reduced-motion`.
