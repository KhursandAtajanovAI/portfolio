# Личный сайт-портфолио (Хурсанд Атажанов)

Чистые HTML, CSS и JS без сборки. Работает на GitHub Pages как есть.

```
index.html      главная
hr.html         страница для рекрутеров и ИИ (статический текст + JSON-LD)
404.html        страница «не найдено»
css/tokens.css  цвета и темы (общие для всех страниц)
css/style.css   шапка, баннер, бланк-резюме, hr и 404
css/sections.css  нижние разделы главной
js/main.js      подставляет тексты из content/ в страницу
js/drum.js      барабан проектов
js/filters.js   фильтры и списки раздела «Меньше слов, больше дел»
js/flow.js      змейка этапов
js/form.js      контакты и форма заказа
js/edit.js      режим редактирования (грузится только при #edit)
content/*.json  все тексты главной
images/         favicon.svg, сюда же avatar.jpg и full.jpg
design/         эталонный макет template2.html (в навигации не участвует)
```

## Локальный запуск

Тексты подгружаются через `fetch`, а он не работает при открытии файла двойным кликом
(`file://`). Запускайте через локальный сервер:

```bash
python3 -m http.server 8000
```

(на Windows: `python -m http.server 8000`) и откройте http://localhost:8000/.
Если JSON не загрузился, на странице остаются заглушки «Текст не загрузился…».

## Публикация на GitHub Pages

1. Создайте репозиторий и запушьте код (ветка `main`).
2. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://USER.github.io/REPO/`. Все пути в проекте относительные.
4. После публикации добавьте в `<head>` страниц абсолютный `og:image`
   (пример лежит комментарием в `index.html`) и поле `url` в JSON-LD в `hr.html`.

## Как менять контент

Правка файла в `content/` = правка сайта, вёрстку трогать не нужно.

| Файл | Что внутри |
| --- | --- |
| `profile.json` | имя, строки в баннере, кнопка |
| `now.json` | блок «Сейчас» |
| `about.json` | «Кто я» |
| `works.json` | «Путь и работы»: `date`, `title`, `text`, `url` |
| `skills.json` | «Навыки и видение» |
| `hours.json` | «Время работы» |
| `links.json` | «Ссылки» и кнопки-ссылки справа |
| `deeds.json` | заголовок, названия и цитаты блоков А, В, С, подписи над списками |
| `projects.json` | проекты для барабана и списка: `title`, `kind` (`site`, `ml`, `it`, `project`), `url` |
| `creative.json` | креативные плитки: `kind` (`draw`, `result`, `ba`), `title`, `image` или пара `before`/`after` |
| `interests.json` | таблица «Что у меня есть»: `kind` (`startup`, `shop`, `charity`, `invest`), `text`, `url` |
| `stages.json` | раздел «Как это происходит»: заголовок, подзаголовок, этапы |
| `contacts.json` | город, телефон, почта, Telegram, WhatsApp, текст согласия, настройки формы |

Везде, где стоит `добавить`, нужно вписать свой текст. Новые записи в `works.json` добавляйте
в начало списка `entries`: они показываются сверху. Пустой `url` значит, что ссылки нет.
Заголовки записей автоматически попадают в подменю «Работы».

`hr.html` специально статический (роботы и ИИ часто не выполняют JS), его тексты правятся прямо в файле.

Картинки для креатива кладите в `images/` и указывайте путь, например `images/work1.jpg`
(квадрат около 600×600 px, до 150 КБ). Пока путь пустой, показывается плитка-заглушка.

## Форма заказа

GitHub Pages статический, письмо сам отправить не может. Поэтому в `content/contacts.json`
есть поле `form_endpoint`.

**Если поле пустое**, форма ничего не имитирует: после проверки полей она честно пишет,
что отправка не подключена, и показывает кнопки «Написать в Telegram» и «Написать в WhatsApp».
WhatsApp откроется с готовым текстом заявки. Telegram не умеет принимать текст в ссылке, поэтому
текст копируется в буфер (и показан в поле ниже), его нужно вставить в чат. Чтобы кнопки заработали,
заполните `telegram` (ник `@name` или ссылка) и `whatsapp` (номер с кодом страны) в том же файле.

**Подключение Formspree** (бесплатно, без своего сервера):

1. Зарегистрируйтесь на https://formspree.io и создайте форму (New Form), укажите свою почту.
2. Скопируйте адрес вида `https://formspree.io/f/abcdwxyz`.
3. Вставьте его в `content/contacts.json` в `"form_endpoint"`, сделайте коммит и запушьте.
4. Отправьте тестовую заявку с сайта и подтвердите почту в письме от Formspree.

**Web3Forms:** адрес `https://api.web3forms.com/submit`, а ключ (Access Key из письма) вставьте в `"form_access_key"`.
Ключ у Web3Forms публичный по замыслу, его не нужно прятать.

Если отправка не удалась (сеть, ошибка сервиса), форма покажет сообщение и те же кнопки мессенджеров.
Введённые данные сайт нигде не сохраняет, они уходят только на указанный адрес. Скрытое поле `_gotcha`
ловит простых спам-ботов. Адрес `form_endpoint` должен начинаться с `https://`.

Правки в `#edit` видны сразу: адрес формы можно поменять в панели «Приём формы» и проверить отправку,
но на сайт он попадёт только после скачивания `contacts.json` и коммита.

## Режим редактирования

1. Откройте сайт (локально или на Pages) с `#edit` в адресе: `http://localhost:8000/index.html#edit`
   (если страница уже открыта, добавьте `#edit` и обновите её).
2. Все тексты станут полями, которые растут по мере ввода. Для записей в «Пути и работах»
   есть кнопки добавления и удаления, под ссылками и кнопками появляются поля адреса.
   Проекты, креативные работы, таблица интересов, этапы и адрес формы правятся в панелях
   с пунктирной рамкой под своими разделами (там же добавление и удаление записей).
3. Внизу нажмите **Скачать JSON**: скачаются только изменённые файлы (`now.json` и т. д.).
   Рядом появляются кнопки «Скачать JSON: файл.json» для каждого изменённого файла отдельно.
   Браузер может спросить разрешение на несколько загрузок.
4. Положите скачанные файлы в `content/` с заменой, сделайте коммит и запушьте.

**Важно:** правка в браузере сама на сайте не публикуется и никуда не сохраняется. Пока вы
не скачали JSON и не закоммитили его, изменения живут только в открытой вкладке.
Обычные посетители режим не видят, он включается только адресом с `#edit`.

## Фото

Если файла нет, показывается силуэт из макета. Положите:

- `images/avatar.jpg` — круглое фото профиля, квадрат 760×760 px (показывается 380 px);
- `images/full.jpg` — фото во весь рост, пропорция 3:5, например 600×1000 px.

Сожмите JPG до 80–150 КБ (например в Squoosh). Размеры в разметке заданы, страница при загрузке не прыгает.
Файл должен называться именно так (`.jpg`).

## Тема и доступность

Светлая и тёмная темы переключаются автоматически по `prefers-color-scheme` (переменные в `css/tokens.css`).
Барабан управляется мышью, пальцем, кнопками и стрелками ← → (фокус на элементе барабана),
у кнопок-фильтров есть `aria-pressed`, поля формы подписаны, ошибки читаются скринридером.
При `prefers-reduced-motion` змейка не рисуется, все карточки видны сразу, анимации отключены. Есть ссылка
«К содержимому», видимый фокус, подменю открывается по Tab и закрывается по Esc,
плавная прокрутка отключается при `prefers-reduced-motion`.
